### **Step 1: Handle form submit**

* Attach an event listener to `#validForm`
* Prevent default submit (`event.preventDefault()`)

👉 This gives you control before submission.

---

### **Step 2: Get all values**

Inside your handler, read:

* name
* email
* password
* confirm
* phone

Also **trim** them.

---

### **Step 3: Clear previous errors**

Before validating:

* Set all error `<p>` elements (`nameErr`, `emailErr`, etc.) to empty text

---

### **Step 4: Validate each field**

Go one by one:

**Name**

* Check empty
* Optional: minimum length (like 3)

**Email**

* Check empty
* Then pattern (basic email format)

**Password**

* Minimum length (e.g., 6 or 8)

**Confirm Password**

* Must match password

**Phone**

* Check only digits
* Length (usually 10 digits in India)

---

### **Step 5: Show errors properly**

Instead of alerts:

* Set `innerText` of error `<p>`
  Example idea:
* `"Name is required"`
* `"Invalid email format"`

---

### **Step 6: Track validation status**

* Use a variable like `isValid = true`
* If any check fails → set `isValid = false`

---

### **Step 7: Final check**

* If `isValid === true` → form is valid (you can submit or show success)

---

### **Small correction in your HTML**

```html
<input type="tel" id="phone">
```

👉 `type="phone"` is not valid, use `tel`
